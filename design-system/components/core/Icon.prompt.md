Clout's 27-glyph line-icon set (24px grid, 2px stroke, round caps, white default) — use for product UI and marketing; recolor via `color` for emphasis.

```jsx
<Icon name="trophy" />
<Icon name="bolt" size={32} color="var(--clout-electric-blue)" />
<Icon name="arrow-right" color="var(--clout-pink)" />
```

Groups: navigation (arrow-left/right, chevron-right/down, external, close, menu), media (play, pause, live, stream), gaming/sports (controller, trophy, medal, target, fire), rewards (gift, coin, star, xp, bolt), UI/social (heart, clock, user, share, check, bell). `ICON_NAMES` exports the full list. Keep stroke at 2px @ 24px; min display 16px.
