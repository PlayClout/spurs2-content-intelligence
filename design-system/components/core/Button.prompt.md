Clout's call-to-action button — the strongest *actionable* element (never fighting the headline or prize). Full-radius pill, athletic italic caps, one glow, trailing circular arrow.

```jsx
<Button>Join Now</Button>
<Button family="secondary" size="small">Learn More</Button>
<Button family="outline" showArrow={false}>Skip</Button>
```

Families: `primary` (solid Action gradient — default conversion), `secondary` (dark + gradient stroke, for busy hero art), `dark` (Carbon + hairline, for bright surfaces), `outline` (quiet contexts). Sizes `large`/`small`. Do NOT stack multiple primary CTAs; one glow only.
