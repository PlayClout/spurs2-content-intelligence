Clout marketing components — reusable campaign parts, transparent-backed, drop over any dark scene.

```jsx
<PrizeCard kicker="WIN A" value="$500" label="GIFT CARD" />
<PriceTag label="IN PRIZES" value="$10,000" />
<PassTag name="OPEN PASS" />
<StatChip value="$50K" label="TOTAL PRIZES" />
<StatusBadge status="live" />
<Countdown days={2} hours={14} minutes={30} />
<Divider />
```

Keep the athletic italic type + gradient treatment; swap copy per campaign. Prize value is pink; pass tags use a gradient outline so they never fight the primary CTA.

Vocabulary: Clout is free to play. Never write "prize pool", "entry", "odds", "bet" or "wager" in campaign copy — prizes are earned through free participation.
