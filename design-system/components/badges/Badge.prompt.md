Achievement / status badge for Clout's gamified engagement system. Carbon fill, gradient rim, italic title.

```jsx
<Badge shape="circle" title="MVP" subtitle="AWARD" rim="action" />
<Badge shape="shield" title="PRO" subtitle="VERIFIED" rim="atmosphere" />
<Badge shape="hexagon" title="XP MAX" subtitle="MILESTONE" rim="atmosphere" />
```

Shapes: circle (achievement), square (rank tier), shield (verification), ribbon (placement), hexagon (XP). Rim `action` for warm/achievement, `atmosphere` for status/tier.
